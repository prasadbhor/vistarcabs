# Photos for Vistar Cabs pages

The site already shows six stock road/landscape pictures on these pages. To use a real photo on a page, drop it in this folder with the exact name below (`.jpg`, `.webp` or `.png`), then rebuild (`npm run build`) or restart `npm run dev`. The photo replaces the stock picture on that page automatically.

**Size:** landscape, at least 1600 px wide, under 400 KB (compress at squoosh.app). **Rights:** only photos you own or that are licensed for commercial use. Keep the main subject in the centre, because text sits over the left side.
